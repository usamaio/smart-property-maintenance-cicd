# Smart Property Maintenance Platform

Smart Property Maintenance is a Django-based web application developed as part of an MSc dissertation project. The platform supports the management of properties, rooms, appliances, warranties, maintenance requests, maintenance schedules, and service records.

## Development and Deployment

The application uses:

- Django for backend development
- GitHub Actions for continuous integration
- Render for application deployment
- SonarQube Cloud for code quality and security analysis
- UptimeRobot for availability monitoring
- Slack for repository and development communication

## Project Status

The application has been implemented and deployed, with automated testing, continuous integration, code quality analysis, deployment monitoring, and repository communication incorporated into the development workflow.
